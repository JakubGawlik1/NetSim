NetSim - Net simulation

How to run:
After cloning repository, create a new directory a run "cmake" and "make" inside of it. Two executables should show up, "tests" and "Netsim".

To test functionality simply run "tests"
For more informations about "Netsim", try running "Netsim --help"
Additionaly there is a "factory.txt" file in main directory which u can use to initialize your own factory.
